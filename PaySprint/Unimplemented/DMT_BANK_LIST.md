## What it is

Master list of **BankId → BankName** for PaySprint DMT beneficiary APIs.

| Item | Value |
|------|-------|
| Columns | `BankId`, `BankName` |
| Row count | **1903** banks |
| Id range (file order) | `1` … `1942` |
| Used by | Bene add / list / verify — field **`bankid`** |

### Usage

- Pass `bankid` (numeric) on `POST /dmt-casa/beneficiary/sendotp` and `add_bene` (and related bene APIs).
- Cache this list in app/DB; refresh when PaySprint ships an updated Excel.
- Do **not** invent bank ids — only values from this master.

### Related APIs

| API | Path |
|-----|------|
| Send Bene OTP | `POST /dmt-casa/beneficiary/sendotp` |
| Add Bene | `POST /dmt-casa/beneficiary/add_bene` |
| Bene List | `POST /dmt-casa/beneficiary/benelist` |
| Bene Name Verify | `POST /dmt-casa/beneficiary/benenameverify` |
